# VAE
## 快速开始
    uv run -m src.train.train_vae --train configs/train/smoke.yaml   # 冒烟（1 轮小批）
    uv run -m src.train.train_vae                                    # 正式训练（300 轮）

## 产物
    save_dir/ 下：vae_epochN.pth（存档）、recon_epochN.png（重建对比）、sample_epochN.png（凭空生成）

├── src/
│   ├── data/

│   ├── models/

│   │   └── vae.py                ← 把零件拼成完整 VAE + 三个"接头" + 重参数化

为什么要固定seed？

一、先看没有固定种子时的世界
深度学习训练里到处在摇骰子：模型初始化的几十万个数字、每轮图片的打乱顺序、每次 forward 的加噪取点（eps）。不固定种子时，每次运行这三样全都不同。这带来一个致命的麻烦：

你把学习率从 2e-4 改成 3e-4，跑完发现平均扣分变低了。请问：这是改动的功劳，还是这次骰子恰好摇得好？

答案是：无法判断。因为你同时改了两个东西——你的改动，和一整套随机起点。深度学习里“随机初始化好坏”造成的差异，量级完全可能盖过你那点改动。这就像想比较两个厨师的手艺，却让两人用不同的食材、不同的灶火、不同的评委——比了个寂寞。

二、固定种子到底买到了什么（三样东西）
固定种子后，随机序列被钉死，你的改动成为两次运行之间唯一的区别。由此买到：

| 买到什么 | 解决什么问题 | 你身边的例子 |
|---|---|---|
| 可对照（控制变量） | 改动 A → 变好，能确定是 A 的功劳，不是运气 | 想比较 lr: 2e-4 和 3e-4？同种子各跑一遍，差异全是 lr 的 |
| 可复现（时光机） | 训练到第 180 轮崩了、出鬼图，能精确重演现场、逐步定位 | 三次冒烟连 867553.6250 每一位都相同——这就是时光机在工作 |
| 可分享（可信度） | 导师、同事、审稿人拿你的代码+种子，能跑出和你一模一样的图与数字 | 结果不能复现的实验，没人敢信 |
