一、一条流水线（心智模型）

整个项目是一条流水线。启动脚本是总装指挥：它从设置清单取数字，从各车间领零件，拼成一次训练。零件之间只靠"你递给我什么、我递回给你什么"（函数的输入和返回值）打交道。

设置清单数字与路径三个 yaml 小文件
备料图片 → 干净的递图助手src/data/
加工小零件 → 整机模型src/models/
工具箱扣分、存档、固定随机src/utils/
总装领零件、拼成训练src/train/（只指挥、不造零件）
三条铁律（两个范本的共同点） ① 启动脚本只指挥、不造零件——范本一的启动脚本只有 4 行，模型结构一行都不写在里面；
② 一个文件只管一件事——模型文件只跟数字打交道，数据文件只管读图，扣分文件只算分；
③ 会调的数字都住进设置清单——代码里不出现 1024、0.0002 这类"魔法数字"，想改就改清单。

二、两个范本怎么拆（我们抄什么）

维度范本一：BBdiffusion-FC范本二：brain-net-diffusionVAE 项目取谁
目录骨架 configs/ + src/{models,train,utils} configs/ + src/{data,models,utils,train.py,eval.py} 两者交集：多取一间"备料屋" src/data/
设置清单怎么分 分三摞：data/ model/ trainer/ 分七八摞（callbacks/logger/trainer/debug…） 学范本一的三分法：data/ model/ train/
模型内部 模型、数据集、训练循环挤在同一个 ae.py 小零件住 models/components/，整机另住一屋 学范本二的分法：components/conv_blocks.py（零件）+ vae.py（整机）
清单怎么读 手写：先给参数设默认值，再用清单里的数字覆盖（ae.py 的 apply_config，第 292 行） 用现成框架全自动完成 学范本一的手写法（不碰那个框架）
训练循环 自己写 for 循环（ae.py 的 main 函数） 一行 Trainer.fit() 全托管 自己写——亲手写出这个循环正是本课目标

四、逐文件职责卡片

目标文件给它什么 → 它还你什么只管的一件事禁止事项
configs/*.yaml — → 数字、路径 存放所有"以后想调"的数字与路径，按数据/模型/训练分三摞 不出现任何 Python 代码
src/data/celeba.py 图片文件夹 → 递图助手 读图、裁图、最后交出一个"每次能递一小把图"的助手 不定义模型、不写训练逻辑
src/models/components/conv_blocks.py 数字格子 → 数字格子 压缩零件（把图一步步变小变厚）、还原零件（原路放大回去） 不出现 mu、logvar、z 这些 VAE 特有概念（第 3 课才登场）
src/models/vae.py 图片 → (还原的图, 两个小账本) 用零件拼出完整 VAE：压缩→取精华→还原，一条龙 不读数据、不算扣分、不管"怎么学"（优化器的事）
src/utils/losses.py (还原图, 原图, 两个小账本) → 扣分数字 算"这次还原得多差" 不含任何模型零件
src/utils/checkpoint.py 模型 → 磁盘文件 存档（存模型的数字）、把一批图拼成一张大图保存 不改动模型
src/utils/seed.py 一个整数 → 无 固定所有随机源头，让实验可复现 —
src/train/train_vae.py 一条命令 → 训练好的存档 读清单 → 领零件 → 训练循环 → 存档出图 不定义任何模型结构（只组装）

五、总装指挥的骨架（第 6 课要写的 main 函数）

所有零件在 main 函数里按固定顺序会合——这个顺序就是上面流水线的顺序：

# src/train/train_vae.py 的 main() 骨架（第 6 课才写，先混个脸熟）
def main(args):
    cfg = apply_config(args)                      # ① 取图纸：用清单里的数字盖掉默认值（学范本一 ae.py）
    set_seed(cfg["seed"])                            # ② 固定随机性
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

六、术语表（大白话词典）

词大白话本项目的实例
模型肚子里有几十万可调数字的程序；训练就是调这些数字ConvVAE
训练看图→算差多少→微调数字，循环几万次main 里的 for 循环
层（layer）模型里的一个"加工步骤"，数字进去、数字出来nn.Conv2d、nn.Linear
卷积层"看图找特征"的基本层；第 2 课手写压缩/还原零件里的每一级台阶
数据集（Dataset）图片文件夹 + "怎么读一张图"的规矩CelebADataset
递图助手（DataLoader）每次抽一小把图递给模型build_dataloader() 造出来的东西
裁图规矩（transform）统一"裁多大、数值化到 0–1"的预处理步骤原 vae.py 第 26–30 行
损失 / 扣分（loss）量化"这次错得多差"的一个数字vae_loss()
优化器照着扣分自动微调模型数字的工具torch.optim.Adam
存档（checkpoint）把模型数字存成文件，像游戏存档save_checkpoint()
state_dict模型全部数字的清单，存档的本体model.state_dict()

整机把零件拼成可从头用到尾的完整模型models/vae.py 的 ConvVAE
工厂函数吃一张设置清单、吐一个造好的东西的函数，让指挥不用知道细节build_dataloader(cfg)
forward模型"被使用"时执行的函数：描述数字怎么流过它ConvVAE 的 forward()
